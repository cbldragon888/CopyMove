关于这个实验

这是一张图片上的方法演示，不是算法排行榜。直接复制保留整块像素；羽化保留中心、混合边缘；色调、多尺度和泊松融合会进一步改变复制内容。所有方法仅修改目标范围，真实变化位置可在掩膜中查看。
